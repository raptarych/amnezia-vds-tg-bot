# Суть

Нужно написать 2 приложения:

1) HTTP API для управления Amnezia VPN на хосте
2) Telegram bot, который будет ходить в API выше и даст интерфейс управления

# Основные сущности

**Ключ** - представляет собой доступ к VPN для одного клиента. Идентифицируется именем ключа.

# Приложения

## HTTP API

Является единым приложением REST API на Python

### Авторизация

Все запросы в API должны принимать заголовок с секретом. Секрет должен сравниваться с эталоном в файле пользовательских файлах на хосте. 

### Функционал

Должен представлять endpoint-ы для следующего функционала:

- API ключей
	- Сгенерировать ключ: запуск на хосте bash-команды `/root/awg/manage_amneziawg.sh add <имя ключа>`. Параметр <имя ключа> должен быть query-параметром запроса.
	- Получить ключ: скачивание контента файла `/root/awg/$keyName.conf` хоста. Параметр <имя ключа> должен быть идентификатором ключа. Могут поддерживаться расширения: `.conf`, `.png`, `.vpnuri`. Не допускать скачивания вне папки по path traversal. Не допускать скачивания других форматов файлов.
	- Удалить ключ: запуск на хосте bash-команды `/root/awg/manage_amneziawg.sh remove <имя ключа>`
	- Список ключей: запуск на хосте bash-команды `/root/awg/manage_amneziawg.sh stats`. В выводе bash-комманды будет список peer-ов AmneziaVPN, для них нужно будет собрать модель DTO и отдать наружу. Пример вывода команды в `secret_stats_example.txt`
- API Amnezia сервера
	- Запуск проверки: запуск на хосте bash-команды `/root/awg/manage_amneziawg.sh check`. Если она возвращает хороший код выхода - отправить пустой 200. Если нет - отправить DTO с ошибкой.
	- Перезапуск: запуск на хосте bash-команды `/root/awg/manage_amneziawg.sh restart`. Если она возвращает хороший код выхода - отправить пустой 200. Если нет - отправить DTO с ошибкой.

### Контракт

API должен предоставлять OpenAPI-спецификацию по всему функционалу. Должен быть файл для генерации API. OpenAPI-спецификация должна храниться в текущем git-репозитории.

### Деплой

Сервис будет работать на Ubuntu 24 как обычное приложение (не в контейнере). Нужен скрипт деплоя который:

1) Скачает зависимости и запустит API
2) Убедится что API доступен снаружи
3) Зарегистрирует для автоматического запуска при рестарте хоста

## Telegram API

Является ботом который хостит Telegram Bot с poll-механикой на Python. Бот предоставляет интерфейс для управления вышеописанного API.

### Авторизация

В некотором файле пользовательских файлов на хосте должен быть yml-файл с секретами. В нём должны быть такие настройки:

- ключ бота
- адрес HTTP API
- секрет HTTP API
- список ников пользователей, которые имеют доступ к боту

Если такого файла не существует - при запуске нужно его сделать с заглушками в данных

### Функционал

Клиент к API должен быть сгенерирован из OpenAPI-документации, которая получилась из вышеописанного API.
Должен предоставлять такой функционал:

- Команда "сгенерировать ключ" - принимает имя ключа, вызывает метод генерации ключа. При успехе метода - скачивает контент ключа в .conf и .png, и отправляет их файлами пользователю в ответе
- Команда "получить ключ" - принимает имя ключа, вызывает метод получения ключа. При успехе метода - скачивает контент ключа в .conf и .png, и отправляет их файлами пользователю в ответе
- Команда "список ключей" - вызывает метод получения списка ключей. Формирует ответ в виде md-таблицы с колонками `Имя          | IP              | Получено | Отправлено | Последний handshake | Статус` и отправляет пользователю
- Команда "перезапустить сервис" - вызывает метод перезапуска сервера

### Деплой

Сервис будет работать на Ubuntu 24 как обычное приложение (не в контейнере). Нужен скрипт деплоя который:

1) Скачает зависимости и запустит сервис
2) Зарегистрирует для автоматического запуска при рестарте хоста

### Документация

В репозитории должно быть человеческое описание команд - как они вызываются, как и какие туда передаются параметры, что вернётся в ответе. Добавь это в claude-скилл разработки.

## Правила написания кода

- Добавь в .gitignore всё что необходимо
- Можно и нужно использовать сторонние популярные зависимости: для Telegram бота, для генерации OpenAPI-документации.
- Используй скиллы из папки /.claude
